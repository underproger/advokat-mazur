# Збірка сторінок (дизайн 3)

Сторінки `3/index.html` і `3/<послуга>.html` генеруються з шаблонів, щоб шапка, футер, меню та перелінковка були однакові на всіх сторінках.

```
pip install jinja2
python3 3/_build/build.py
```

- `templates/base.j2` — head, шапка з мегаменю, футер, модалка, мобільна панель
- `templates/home.j2` — головна (1:1 з `index-design.html`)
- `templates/service.j2` — шаблон сторінки послуги
- `templates/cases.j2`, `templates/case.j2` — розділ «Кейси» (`keysy.html`) і сторінка кейсу (`keys-<slug>.html`)
- `data_cases.py` — кейси (**зараз ДЕМО-приклади — замінити реальними перед запуском**); поле `service` = slug послуги, до 3 кейсів автоматично виводяться на сторінці цієї послуги
- `data_services.py` — контент послуг (порядок = порядок у меню/футері/на головній)
- `build.py` — дані сайту (телефон, email), відгуки та FAQ головної

Нова послуга = новий словник у `SERVICES` + перезбірка: вона сама з'явиться в меню, футері, на головній і в блоках «Інші напрями».

`index-design.html` — оригінальний експорт дизайну головної (еталон).

Анімації: базові — `assets/js/main.js` (+ `main.css`), розширені — `assets/js/wow.js` + `assets/css/wow.css` (GSAP, ScrollTrigger, Lenis з CDN), підключені на всіх сторінках через `base.j2`. Повний прелоадер показується лише при першому заході в сесії, далі — коротка шторка. `data-motion="force"` на `<html>` вмикає анімації навіть при системному «зменшенні руху».

## Мови (UA / RU)

Українська — у корені `3/`, російська — у `3/ru/` (ті самі імена файлів, `page.root = "../"` для assets). Перемикач мов — випадний список у шапці (і в мобільному меню), `hreflang` у `<head>`.

- Рядки шаблонів обгорнуті в `{{ _("…") }}`, переклад — `i18n/ru_templates.py` (`TPL = {"укр": "рус"}`).
- Рядки даних (послуги, кейси, відгуки, FAQ) перекладаються за md5-хешем українського тексту: `i18n/ru_data_*.py` (`DATA = {"хеш": "рус"}`).
- Змінили український текст або додали новий — після збірки з'явиться `i18n/missing_ru.tsv` зі списком неперекладених рядків (на RU-сторінці поки лишиться українська). Додайте переклади й перезберіть — файл зникне.
- Контакти RU (ім'я, адреса, години) — `SITE_I18N` у `build.py`; підписи курсора/кнопок у JS — словники RU у `main.js` / `wow.js`.
